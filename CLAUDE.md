## Commands

Godot 4.3 is installed at `/home/jake/bin/godot` (`godot` is on PATH).

## GDScript conventions

- Use static type hints everywhere: typed variables (`var speed: float = 5.0`), typed function params and return types (`func move(delta: float) -> void:`), and typed arrays (`Array[Node]`). Prefer `:=` inferred typing only when the right-hand type is obvious.
- Prefer `@onready var node: Type = %NodeName` (unique-name access) over `$Path` for node references.
- Use `class_name` for reusable types so they resolve as static types elsewhere.
- `gdscript/warnings/untyped_declaration` is enabled in `project.godot` — keep new code warning-clean.

## Notes

- Headless (`godot --headless`) uses a dummy renderer: it validates scene loading and GDScript parsing but **not** shader compilation or visual output. Shader changes must be verified with a real GPU run (`godot` with a display).

- `.godot/` is generated by the engine and gitignored — never edit it; it is recreated on editor open/import.
- Scene (`.tscn`) and resource (`.tres`) files are text — hand-editing is possible but regenerating UIDs and `ext_resource` IDs by hand is error-prone; prefer the editor for structural changes.
- don't ever write comments
